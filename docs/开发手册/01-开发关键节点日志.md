## 4. 阶段四：企业化补全（09-11）

### 节点 4-1 · 景点攻略语料 RAG 通道

- `TravelGuideStore`（`data/org/guide_docs`，与 `policy_docs` 分开存储防企业/个人语料串档）+ `/guides` 路由（CRUD / search / reindex）。
- **决策**：景点语料仅 `scene=personal` 召回——商务差旅不做旅游推荐。
- 8 篇种子语料（西湖 / 灵隐寺 / 熊猫基地 / 宽窄巷子 / 故宫 / 八达岭 / 兵马俑 / 亚龙湾）；13 用例（含双语料不串档、四个企业场景不召回）。
- **踩坑（重要）**：Edit 报成功但静默未落盘 → 自此铁律「**编辑后必须 grep 回读校验，信验证不信返回值**」。

### 节点 4-2 · 身份 / 鉴权大修

- `SignedSession`：HMAC-SHA256 无状态签名 token（exp 内嵌、compare_digest）；`revoke()` 为 no-op，改 secret 即全量失效。
- `resolve_user_id()` 优先级：Bearer > 显式 session_id > workspace；属主校验只拒「声明了别人」（防 IDOR 又不误伤）。
- 测试 +13（全量 121 passed）。

### 节点 4-3 · 自助注册

- `POST /auth/register`：注册即签发 token（注册即登录）；用户名 `^[A-Za-z0-9_.-]{3,32}$`、大小写不敏感查重；保留名 `{admin, web-user, default}`（与组织侧 employee_id 同值）。
- **角色不接受客户端指定**（新账号一律 user，防自封管理员）。
- 口令 sha256 → pbkdf2-sha256 12 万轮（stdlib 免依赖）；旧记录验证通过后自动升级；比对改 `secrets.compare_digest`。
- LoginPage 登录 / 注册双模式；+29 用例（全量 150 passed）。

## 附录 C · 踩坑速查（按主题）

**工具链**
- Edit 可能报成功但未落盘（EBUSY 竞态）→ 每次修改后 grep 回读校验。
- bat 必须 CRLF + 纯 ASCII；Write 默认写 LF，写完用 Python 读字节复验。
- `.gitignore` 不支持行内注释。
- 根目录清杂物前先查引用（bench_models.json 差点误删——抗打假证据）。

**环境**
- 沙箱按进程树回收服务（agent 拉起的服务活不过命令结束）→ 未经用户要求不主动 start；常驻靠用户双击 start.bat。
- 本机代理劫持 localhost → `trust_env=False`。
- Git Bash 缺 coreutils → 目录/文件操作用受管 Python。
- pytest 临时目录网络路径报错 → `--basetemp=./.pytest_tmp`。

**代码 / 接口**
- ServiceClient 每请求新建 session（keep-alive 半关连接复用致偶发 404）；post 无 timeout 参数。
- 三服务同名顶层 `api` 包 → 服务内一律相对导入。
- FastAPI 422 与 Optional 参数；中文乱码 ISO-8859-1。
- mock 数据源随机 → 验证去重用稳定数据；接口验证用 TestClient。
