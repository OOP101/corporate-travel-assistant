# 企业智行 · Corporate Journey Hub — 项目介绍

> 大模型驱动的企业差旅智能助手 · 三微服务架构 · 行前规划 / 行中保障 / 行后归档全链路
> 文档版本：2026-08-29 · 配套材料见 `docs/`（项目经历 / 面试准备 / 优化策略）

---

## 一、项目概述

**企业智行**是一个面向企业内部的智能差旅管理平台。员工用一句话描述出行需求（如"9月15号广州飞北京出差，16号上午拜访国贸客户，17号下午返程"），系统即可生成结构化的多日行程，并在行前自动完成差旅政策检查与审批流转，行中持续监控航班、天气并主动推送异常提醒。

**解决的痛点**：

| 传统方式 | 企业智行 |
|---|---|
| 行程安排分散在聊天记录、邮件、Excel，人工整理费时 | 一句话生成完整多日行程，自动保存可管理 |
| 差旅标准靠记忆执行，超标难发现 | 生成即检查政策，超标自动提示并发起审批 |
| 航班延误、天气异常靠员工自己刷 App | 定时监控订阅，异常分级提醒主动推送 |
| 常用出差线路每次重新安排 | 行程一键存为模板，复用只需改日期 |
| 出行中航班/车次有变无人通知 | 航班与铁路 12306 车票停运/无票主动推送 |

## 二、系统架构

```
┌────────────────────────────────────────────────────┐
│           前端工作台 (React 19 + Vite, :3001)        │
│   智能助手 / 差旅行程 / 实时监控 / 企业管理 / 系统管理   │
├──────────────┬──────────────────┬──────────────────┤
│  行智 Journey Hub (:8001)        │  登录认证 · 意图路由 │
│  LangGraph 编排 · 会话管理 · 系统配置              │
├──────────────┬──────────────────┤
│ 策程 Planner Core (:8002)   │ 感知 Sense Engine (:8003) │
│ 行程生成/CRUD/政策/审批/RAG  │ 航班/天气/路况监控推送     │
└──────────────┴──────────────────┘
          shared 公共层：LLM管理器 / 鉴权 / 存储 / 指标 / 日志
```

三个 FastAPI 微服务按职责拆分：**编排**（对话入口、LangGraph 意图路由：规划/问答/管理/应急）、**规划**（行程生成与全业务逻辑）、**感知**（定时监控型任务）。服务间用 REST + SSE 通信，公共能力下沉 `shared/` 层（LLM 统一管理、API Key 鉴权、JSON 存储基类、Prometheus 指标、结构化日志、HTTP 客户端），零重复代码。

## 三、核心功能

### 3.1 一句话生成行程（流式）
两阶段生成：大模型先提取参数（目的地/日期/人数/预算），再按内置规划规则生成多日行程 JSON（交通、住宿、会议、餐饮、出行清单、预算预估）。SSE 流式输出——用户 0.1 秒看到"正在生成"反馈，完成后行程摘要、政策检查结果、审批状态渐进渲染。支持混元 / DeepSeek / GLM 多模型，管理员可在线配置与热切换。

### 3.2 企业化管控闭环
行程生成后自动匹配职级差旅政策、逐项检查费用超标 → 自动创建审批单（审批人 = 直属主管）→ 行程进入"待审批"锁定（不可修改/重排）→ 主管通过行程生效，拒绝则作废。组织架构、差旅政策、审批记录均有独立管理页面。

### 3.3 RAG 差旅政策知识库
政策文档（报销制度、审批制度、住宿标准）入库，问答时先检索相关原文再让大模型引用作答，回答带原文摘录（excerpt）与相似度，保证**有依据、可解释**。Embedding 三后端可插拔（本地 bge-large-zh 私有化 / OpenAI 兼容 API / 关键词降级），失败自动熔断。

### 3.4 实时感知与应急
APScheduler 每 5 分钟轮询订阅任务（航班动态/**铁路 12306 车票**/天气预警/路况/景点状态），异常按严重度分级（critical/warning/info）生成提醒推送。铁路监控覆盖车次停运、无票候补、余票正常（12306 官网接口免 Key，反爬拦截自动降级模拟数据）。应变重排：航班延误、景点闭园后自动调整后续时间线，可推荐替代方案。对话中可触发应急协助（应急电话/证件丢失/就医指引）。

### 3.5 卡片式对话与补充
对话回答自动解析为结构化卡片：行程卡（点击跳详情页）、政策检查卡、审批卡；每次回答按意图推荐补充追问（可一键追问）。政策类问答自动检索差旅政策知识库原文作为回答依据（RAG），回答注明出处文档。

### 3.6 行后归档
行程总结（概览/每日回顾/偏差分析/花费统计）、分类费用统计、常用线路模板复用。

### 3.6 登录与权限
账号登录（Token 24h），角色分管理员/普通员工：普通用户见工作台，企业管理与系统管理仅管理员可见（前端隐藏 + 后端接口 403 双重防护）。系统管理页支持可用模型列表维护、默认模型切换与 LLM 服务商（接口地址/Key）在线热更新——配置修改立即生效，无需重启；对话与行程生成的模型选择全链路透传。

## 四、技术亮点

**1. 全链路降级兜底**——任何外部依赖缺失都能完整运行：LLM 不可用走模板行程、向量检索降级关键词、四类感知数据源降级 Mock、模型列表拉取失败回退内置列表。演示零配置。

**2. 真流式体验**——问答首字 1.3 秒（PRD 要求 3 秒），规划请求首帧 0.1 秒；独立 error 帧协议保证错误永不污染正文数据。

**3. 生产级问题治理**——修复 async 路由同步调用阻塞事件循环（单请求曾可卡死整个服务）、生成器并发串单、JSON 存储非原子写等隐患，均有 E2E 回归锁定。

**4. 安全防线**——API Key 鉴权（dev 后门仅开发环境生效）、行程属主校验防越权、口令哈希存储、管理接口角色拦截、密钥脱敏展示。

## 七、快速开始

```bash
# 后端（无需 Docker）
pip install -r requirements.txt
cp .env.example .env          # 填入 LLM API Key（留空自动降级演示模式）
python scripts/start_local.py # 一键启动三个服务 (8001/8002/8003)

# 前端
cd frontend && npm install && npm run dev   # http://localhost:3001

# 演示账号
管理员：admin / admin123
员工：  web-user / 123456
```

主流程演示路径：登录 → 首页输入「9月15号广州飞北京出差，16号上午拜访国贸客户，17号下午返程」→ 观察流式生成 → 行程页查看/管理 → 系统管理页切换模型 → 审批页处理待审批单。
